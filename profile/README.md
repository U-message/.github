# U message

**Fast, secure and free messenger for Android and iOS.**

U message is an **unofficial Telegram client** created and maintained by [@Javokhiir](https://github.com/Javokhiir).
It is built on the [Telegram API](https://core.telegram.org/api) and is not affiliated with, endorsed or sponsored by Telegram.

## ✨ Features

- 💬 Cloud chats, groups, channels and bots
- 🔒 End-to-end encrypted secret chats
- 📞 Voice and video calls
- 📸 Stories with a pro camera and lenses
- 🗺️ Live friend map
- 📄 Built-in document reader
- 👥 Up to 20 accounts in one app
- 🌍 Uzbek, Karakalpak, Russian and English interface
